# 02 — 透视表（Pivot Tables）

> Excel 里最强大的数据汇总工具。多数"用 SUMIFS+VLOOKUP 想 30 分钟"的需求，透视表 30 秒解决。

## 何时用透视表

✅ 用透视表：
- 数据有"重复行"，需要按某个字段分组汇总（销售按地区/月份/品类）
- 需要交叉分析（行 = 月份，列 = 地区，值 = 销售额）
- 需要快速切换汇总维度（"看一下按品类"→"再看按渠道"）
- 数据 > 1000 行，写公式会卡

❌ 不用透视表：
- 需要复杂条件组合（用 SUMIFS）
- 数据 < 50 行，眼睛能数清的（直接用公式）
- 需要让结果"动态联动"其他公式（透视表是静态的，刷新才更新）

## 创建透视表（4 步）

### 1. 准备数据

数据必须满足"**整齐表**"：
- 第 1 行是表头
- 每列是一个字段
- 每行是一条记录
- 没有合并单元格
- 没有空行（特别是数据中间）

❌ 错误示例：
```
  日期       北京   上海   广州
2024-01     100    200    150
2024-02     ...
```

✅ 正确示例：
```
  日期       城市   销售
2024-01      北京    100
2024-01      上海    200
2024-01      广州    150
2024-02      北京    ...
```

如果你的数据是错误格式，用 **Power Query 的"逆透视列" / Unpivot** 转成正确格式。

### 2. 插入透视表

`Ctrl + A` 选中数据 → `插入` → `数据透视表` → 选放在新工作表。

### 3. 拖字段

| 区域 | 拖什么 |
|---|---|
| **筛选**（Filters） | 想做"切片"的字段（年份、产品类别） |
| **行**（Rows） | 维度的"垂直"拆解（如"日期" → 按月） |
| **列**（Columns） | 维度的"水平"拆解（如"地区"） |
| **值**（Values） | 数值（销售额、订单数） |

### 4. 调整值的"汇总方式"

默认是"求和"。点值字段 → 值字段设置 → 改成：
- **求和** Sum（最常用）
- **平均值** Average
- **计数** Count（注意：忽略空值；要算所有行用 COUNTA）
- **最大值/最小值** Max/Min
- **方差/标准差** Var/StdDev
- **占总和的百分比** % of Grand Total ★（KPI Dashboard 必用）
- **累计求和** Running Total ★（增长曲线必用）

## 7 个实用透视表场景

### 场景 1：销售额按月 × 地区交叉

```
行：日期（自动按月分组）
列：地区
值：销售额（求和）
```

**生成的样子**：

| 月份 | 北京 | 上海 | 广州 | 总计 |
|---|---|---|---|---|
| 2024-01 | 100 | 200 | 150 | 450 |
| 2024-02 | 120 | 180 | 160 | 460 |

### 场景 2：Top N 销售产品

```
行：产品名
值：销售额（求和）
```

然后右键 → 排序 → 按销售额降序。

进一步用"标签筛选" → "前 10 项" → 取 Top 10。

### 场景 3：渠道贡献占比

```
行：渠道
值：销售额（求和）
值字段设置 → 显示方式 → "总计的百分比"
```

| 渠道 | 占比 |
|---|---|
| 电商 | 45.2% |
| 线下 | 32.1% |
| 团购 | 22.7% |

### 场景 4：累计销售曲线

```
行：日期（按日）
值：销售额（求和）
值字段设置 → 显示方式 → "按某一字段汇总" → 基本字段=日期，基本项=（上一项），类型=运行总和
```

得到的就是"累计销售"，可以直接画折线图。

### 场景 5：同比/环比增长

```
行：月份
列：年份
值：销售额（求和）
```

然后值字段设置 → 显示方式 → "差异百分比" → 基本字段=年份，基本项=（上一项）。

得到的就是同比增长率。

### 场景 6：分组分析（年龄段、价格区间）

```
行：年龄（数值字段）
值：用户数（计数）
```

右键年龄列 → 创建组 → 起始 18，终止 65，步长 10。

得到 18-27 / 28-37 / 38-47 ... 分组。

### 场景 7：切片器（Slicer）+ 动态 Dashboard

插入透视表后：`插入` → `切片器` → 选筛选字段（如"地区"）。

然后你会得到一个可点击的按钮组，点击切换查看不同地区。

切片器可以**同时控制多个透视表 + 透视图**——这是做 Dashboard 最快的方式。

## 透视表 5 大常见坑

### 坑 1：源数据更新了但透视表没变

透视表是**快照**，不会自动跟随源数据更新。要刷新：

- 右键透视表 → 刷新
- 或 `Alt + F5`
- 或：透视表选项 → 数据 → 勾选 "打开文件时刷新数据"

### 坑 2：源数据加了新行透视表没识别

如果数据范围是固定的（如 `A1:E100`），加到 101 行不会被识别。

**永久解决方法**：
1. `Ctrl + T` 把数据转成"表"（Table）
2. 然后基于"表"建透视表
3. 加新行自动被表识别 → 透视表刷新即可看到

### 坑 3：日期不能按月/年分组

通常是因为日期列**有文本值或空值**。检查：
- 该列里有没有混入非日期的字符串（如 "未填写"）
- 该列单元格格式是不是真的是日期（按 F2 看，左对齐 = 文本，右对齐 = 真日期）

### 坑 4：计数字段有空白行

如果你拉的字段里有空值，透视表会出现 `(空白)` 行。

修复：
- 数据源的空值用空字符串或 0 填充
- 或者透视表里筛选掉 `(空白)`

### 坑 5：合并单元格 / 计算字段嵌套不正常

**合并单元格在数据源中是大忌**。透视表会把合并的"主单元格"当一行，其他被合并的当空。

**解决**：取消合并 + 用 `Ctrl + G`（定位）→ 空值 → `=` + 上箭头 + `Ctrl + Enter` 把空格批量填充。

## openpyxl 创建透视表（高级）

openpyxl 对透视表的**写**支持有限。常见做法：

### 方法 1：基础透视表

```python
from openpyxl import Workbook
from openpyxl.pivot.table import TableDefinition, PivotField, PivotFieldItem
from openpyxl.pivot.cache import CacheDefinition

# 这个 API 复杂且文档有限，建议参考官方 docs
# 多数情况下用方法 2 更实际
```

### 方法 2：用 pandas 生成"汇总数据"+ 写到 Excel

```python
import pandas as pd

df = pd.read_excel('source.xlsx')
pivot = pd.pivot_table(df, index='date', columns='region', values='sales',
                        aggfunc='sum', fill_value=0)
pivot.to_excel('pivot_result.xlsx')
```

虽然不是真正的"透视表"对象，但效果一样且更简单。

### 方法 3：用模板法

提前在 Excel 里建好带透视表的模板 → openpyxl `load_workbook`保留它 → 修改源数据 → 保存 → 用户打开后右键刷新。

## 必背公式

- `Ctrl + A`：选中相邻数据
- `Ctrl + T`：把数据转成"表"
- `Alt + N + V`：创建数据透视表（菜单快捷键）
- `Alt + F5`：刷新当前透视表
- `Ctrl + Alt + F5`：刷新所有透视表

## AI 常编错的地方

| AI 编的 | 实际应该 |
|---|---|
| "这是动态透视表..." | 透视表本身不是动态的，要 Ctrl+T + 刷新才动态 |
| "切片器自动多表联动" | 必须显式"报表连接" 才能控制多表 |
| openpyxl 的 PivotTable API | 写起来 API 复杂，简单场景用 pandas pivot_table 更好 |
| 用 SUMIFS 模拟透视表 | 数据 > 1000 行就慢，应该直接用透视表 |
